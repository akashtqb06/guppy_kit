# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for Guppy Kit. ADRs capture significant decisions — the context, the choice made, and its consequences. They are **immutable once accepted**: if a decision changes, a new ADR is written that supersedes the old one.

## Index

| ADR | Title | Status |
|---|---|---|
| [0001](0001-modular-monolith.md) | Modular monolith over microservices | Accepted |
| [0002](0002-tool-sdk-contract.md) | Tool SDK contract as the core platform primitive | Accepted |
| [0003](0003-three-interface-model.md) | One implementation, three surfaces (UI / REST / MCP) | Accepted |
| [0004](0004-artifact-system.md) | Artifacts as the tool composition glue | Accepted |
| [0005](0005-phase-separation.md) | Capability Layer before Intelligence Layer (hard gate) | Accepted |
